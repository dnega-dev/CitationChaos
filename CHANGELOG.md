## Unreleased

## 0.1.0

### Added

- Validated standard-library schemas for corpora, sources, spans, claims,
  citations, answers, mutations, expected responses, and run results.
- Eleven deterministic evidence, provenance, currency, integrity, availability,
  and resolvability mutation operators.
- User pipeline adapter loading and an included deterministic reference adapter.
- Six structural mutation-response checks.
- `init`, `mutate`, `run`, and `operators list` CLI workflows.
- Text, JSON, JUnit XML, and SARIF 2.1.0 output.
- Synthetic energy and transit seeded corpora.
- Standard-library unit and end-to-end test suite.
